# Допуск СБ — офлайн-инструмент

Собирает файлы для согласования допуска сотрудников в СБ Сбербанка. Работает внутри телефона или компьютера: паспортные данные никуда не отправляются.

## Как устроена защита

- Странице запрещены любые сетевые запросы (Content-Security-Policy: `connect-src 'none'`, запрет сторонних адресов и отправки форм). Запрет соблюдает сам браузер, даже если в коде была бы ошибка.
- При каждом запуске инструмент проверяет запрет и показывает «Отправка данных заблокирована». Если вместо этого красное «Защита не работает» — данные не вводить.
- Люди хранятся только в памяти страницы. На устройство ничего не записывается. Закрыли — данных нет. Свёрнут больше 15 минут — список очищается.
- На устройстве запоминается только последний номер исходящего.
- В репозитории нет людей, шаблонов, печати и подписи.
- Шаблоны письма и списка (с печатью и подписью) загружаются в инструмент один раз на каждом устройстве и хранятся только в браузере этого устройства.
- В готовых Word и Excel убирается невидимая картинка-счётчик со ссылкой на dms.sberbank.ru, которая была в шаблонах Сбера: открытие файла никуда не обращается.

## Установка на GitHub Pages (один раз)

1. GitHub → New repository → имя, например `sb-dostup` → Public → Create.
2. Add file → Upload files → перетащить все файлы из архива, включая папку `vendor` → Commit changes.
3. Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save.
4. Через 1-2 минуты адрес появится там же: `https://<логин>.github.io/sb-dostup/`.
5. Проверить, что на аккаунте GitHub включена двухфакторная защита.

## iPhone

1. Настройки → Приложения → Safari → Загрузки → «На iPhone» (иначе файлы уйдут в iCloud).
2. Открыть адрес в Safari → «Поделиться» → «На экран Домой».
3. Запустить с иконки один раз при интернете: инструмент сохранится в телефоне и дальше работает без сети.

## Компьютер

Открыть адрес в Chrome, Edge или Яндекс Браузере. Для значка: меню браузера → «Установить приложение». После первого открытия работает без интернета.

## Первый запуск на каждом устройстве

Раздел «Бланк» → выбрать шаблон письма (.docx) и шаблон списка (.xlsx). Инструмент проверит, что нашёл все поля, и сохранит шаблоны на устройстве. Копии шаблонов держите в «Файлах», в папке «На iPhone»: если браузер когда-нибудь очистит хранилище, их достаточно выбрать заново.

## Что собирается

- «Письмо на допуск ДД.ММ.ГГГГ.pdf» — из вашего бланка: номер и дата, договор банка, ГОСБ и регион, срок (+6 месяцев), таблица людей.
- «Приложение Список сотрудников ДД.ММ.ГГГГ.xlsx» — из вашего шаблона: строка на человека, серия и номер паспорта без апострофа, дата рождения датой, сгенерированный телефон, номер договора, ссылка на письмо под таблицей.
- «Письмо на допуск ДД.ММ.ГГГГ.docx» — тот же бланк в Word, про запас.

Кнопка «Отправить» передаёт PDF и Excel в меню «Поделиться» (например, в Яндекс Почту).

## Обновление

Загрузить новые файлы в репозиторий поверх старых. Телефон подхватит новую версию при следующем запуске с интернетом (иногда нужно открыть инструмент дважды).

## Состав

`index.html`, `app.js`, `app.css` — интерфейс; `core.js` — разбор и проверки; `io.js` — чтение Excel, Word, PDF; `fill.js` — заполнение шаблонов; `docx-render.js` и `pdfgen.js` — сборка PDF из письма; `gosb.js` — справочник ГОСБ и договоров; `sw.js`, `manifest.webmanifest`, иконки — работа без интернета; `vendor/` — JSZip, pdf.js и шрифт Liberation Serif (лицензии в той же папке); `tools/` — скрипт подготовки шрифта.
